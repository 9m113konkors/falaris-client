# Falaris client
Best vibecoded hack client
# Building
1) clone the repository with 
```bash
git clone https://github.com/9m113konkors/falaris-client.git
```
2) run
```bash
./gradlew build
```
3) find the ```falaris-client``` folder on your local machine and navigate to ```/build/libs``` to get the ```.jar``` file.
